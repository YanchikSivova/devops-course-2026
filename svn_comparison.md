1. Почему ветвление в Git дешёвое, а в SVN дорогое?
В Git ветка — это просто ссылка на коммит (файл с хешем), ничего не копируется. В SVN ветка — это копия директории в репозитории (trunk → branches/...), то есть отдельное дерево.

2. Можно ли в SVN коммитить без интернета?
Нет. SVN централизованный: история и коммиты живут только на сервере. Офлайн можно редактировать файлы, смотреть diff/status, делать revert — но не commit.

3. Когда SVN предпочтительнее Git?

- Большие бинарные файлы (Git тянет всю историю при clone).
- Нужны права доступа на уровне отдельных папок/файлов.
- Требуется строгий аудит с последовательными ревизиями (регуляторика).
- Команда не-программистов (художники, инженеры) — проще модель.
- Legacy-инфраструктура: миграция не окупается.
