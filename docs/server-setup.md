# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
*   **Объём оперативной памяти:** 2048 МБ
*   **Количество ядер процессора:** 2
*   **Объём диска:** 25 ГБ (динамически расширяемый)

## 2. Сетевые интерфейсы
*   **Адаптер 1 (NAT):**
    *   *Полученный адрес:* 10.0.2.15
    *   *Назначение:* Обеспечение доступа виртуальной машины в Интернет (для обновления пакетов и установки ПО).
*   **Адаптер 2 (Host-only / Виртуальный адаптер хоста):**
    *   *Полученный адрес:* 192.168.56.101
    *   *Назначение:* Прямой доступ с хостовой системы к виртуальной машине (используется для подключения по SSH и в последующих работах).

## 3. Правило проброса портов
*   **Адаптер:** 1 (NAT)
*   **Порт хостовой системы:** 2222
*   **Порт гостевой системы:** 2222
*(Правило настроено для перенаправления SSH-трафика с хоста на нестандартный порт сервера).*

## 4. Учётные записи
*   **devops:**
    *   *Группы:* devops, sudo (добавлена через `usermod -aG sudo devops`).
    *   *Способ аутентификации:* По SSH-ключу (сгенерированному на хосте и размещенному в `~/.ssh/authorized_keys`).
*   **student / vboxuser** (базовая учётная запись, созданная при установке):
    *   *Группы:* sudo.
    *   *Способ аутентификации:* По паролю.

## 5. Служба SSH
*   **Порт:** 2222
*   **Расположение файла конфигурации:** `/etc/ssh/sshd_config.d/99-hardening.conf`
*   **Изменённые директивы и их значения:**
    *   `Port 2222`
    *   `PermitRootLogin no`
    *   `PasswordAuthentication no`
    *   `PubkeyAuthentication yes`
    *   `PermitEmptyPasswords no`
    *   `MaxAuthTries 3`
    *   `LoginGraceTime 30`
    *   `AllowUsers devops`
    *   `X11Forwarding no`
    *   `ClientAliveInterval 300`
    *   `ClientAliveCountMax 2`
*(Примечание: отключен сокет `ssh.socket`, служба запущена через `ssh.service`).*

## 6. Правила межсетевого экрана (UFW)
*   **Политики по умолчанию:**
    *   Входящие (incoming): `deny`
    *   Исходящие (outgoing): `allow`
*   **Перечень правил:**
    *   `2222/tcp` — `LIMIT` (SSH rate-limited)
    *   `80/tcp` — `ALLOW` (HTTP)
    *   `443/tcp` — `ALLOW` (HTTPS)
*   **Логирование:** Уровень `medium`.

## 7. Снимки состояния
*   **01-clean-install** — Создан после первой установки и обновления системы.
*   **02-keys-configured** — Создан после настройки ключевой аутентификации для пользователя devops.
*   **03-ssh-hardened** — Создан после изменения конфигурации SSH и отключения паролей/root.

## 8. Веб-сервер
* **устанавливаемый пакет** - nginx
* **путь к конфигурации ресурса** - /etc/nginx/sites-available/* * **devops-site** - /var/www/devops-site 
* **каталог ресурса, его владелец и права**
    -  /var/www/devops-site 
    - devops:devops 
    - 755
* **пути к сертификату и ключу, их права**
    -  /etc/ssl/certs/devops.crt (владелец root, права 644 / -rw-r--r--) 
    - /etc/ssl/private/devops.key (владелец root, права 600 / -rw-------)
* **команда формирования сертификата, срок его действия**
    - 365 дней (1 год)
```
sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout /etc/ssl/private/devops.key \
  -out /etc/ssl/certs/devops.crt \
  -subj "/CN=devops.local" \
  -addext "subjectAltName=DNS:devops.local"
```
